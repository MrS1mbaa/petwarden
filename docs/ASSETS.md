# Assets and provenance

| Asset | Source |
| --- | --- |
| `assets/brand/*` (app icon, adaptive and monochrome icons, notification icon) | Original. The raster icon was generated with an image model; the monochrome and notification glyphs are hand-written SVG. |
| `assets/illustrations/dog-corgi.webp`, `dog-beagle.webp` | Original, generated with an image model from text prompts only (no reference images). Transparent WebP, quality 90. |
| `assets/placeholders/dog-*.webp` | Pictures for pets without a photo: square 512 px crops of the corgi and beagle above plus a dachshund and a samoyed generated with the same text prompt. |
| `assets/placeholders/cat-tabby.webp`, `rabbit-lop.webp`, `hamster.webp` | Original, generated by the author with an image model from text prompts in the same style. |
| `assets/lottie/empty-pet.json` | Original. Generated by `scripts/create-empty-pet.cjs`. |
| `assets/lottie/check-confetti.json` | Original. Generated by `scripts/create-check-confetti.cjs` (the script reproduces the shipped file exactly). |
| `assets/fonts/SpaceGrotesk-*.otf` | Space Grotesk by Florian Karsten, SIL Open Font License 1.1 (`assets/fonts/OFL.txt`). |
| Material Symbols font (not in `assets/`, bundled into the APK) | Google, Apache License 2.0, via `@expo-google-fonts/material-symbols` → `expo-symbols` → `expo-router`. Its license text is in `licenses/npm.json`. |
| `docs/screenshots/*.png` | Screenshots of this app showing a fictional demo pet ("Biscuit"); no real user data. |

Apart from the Material Symbols font, the app contains no third-party artwork. Personal photos are always supplied by the user and stay on the device.
